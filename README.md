# 🏦 Agentic SOP Intelligence & Decision Support Assistant

> **EXL Hackathon 2026** · Built on EXL Agentic AI Sandbox

An AI-powered chatbot that helps bank operations staff navigate Standard Operating Procedures (SOPs) in real time — answering process questions, identifying escalation paths, and surfacing compliance requirements, all sourced strictly from SOP documents.

---

## 🚨 Problem

Operational teams use SOPs stored as Word documents. These are static and hard to navigate during live execution. Staff struggle with:

- ❓ What is the next step in this process?
- 📞 Who do I contact or escalate to?
- ⚖️ What compliance rules apply here?
- 🔄 When the SOP changes, how do I know?

---

## ✅ Solution

An **Agentic AI chatbot** that ingests SOP Word documents and provides instant, accurate answers — using a multi-agent architecture where each agent specialises in a different type of question.

**Key constraints respected:**
- ✅ No LLM training — uses retrieval-based SOP reasoning only
- ✅ Answers come exclusively from SOP content
- ✅ Enterprise-safe and fully explainable
- ✅ Works with existing Word documents — no document migration needed

---

## 🏗️ Architecture

```
User Question
      │
      ▼
┌─────────────┐
│   Router    │  ← Classifies the question type
│   Agent     │
└──────┬──────┘
       │
  ┌────┴─────────────────────┐
  │                          │                          │
  ▼                          ▼                          ▼
📋 Guidance Agent    📞 Escalation Agent     ⚖️ Compliance Agent
"What is step 3?"   "Who do I contact?"    "Which regulation applies?"
"What to do next?"  "How do I escalate?"   "What is the MLA cap?"
       │                          │                          │
       └────────────┬─────────────┘
                    ▼
            Answer sourced
            from SOP only
```

### Agents

| Agent | Handles | Colour |
|---|---|---|
| 🔀 Router | Reads the question, picks the right agent | — |
| 📋 Task Guidance | Next steps, process flow, timelines, how-to | Blue |
| 📞 Escalation & Ownership | Contacts, escalation paths, who is responsible | Red |
| ⚖️ Compliance | Regulations, legal requirements, audit rules | Green |
| 🔄 SOP Watcher | Detects Word doc changes and auto-reloads SOP | — |

## 🚀 Quick Start

### 1. Clone the repo

```bash
git clone https://github.com/RohitKankhedia/agentic-sop-assistant.git
cd agentic-sop-assistant
```

### 2. Install dependencies

```bash
pip install python-docx groq streamlit
```

### 3. Add your SOP

Place your SOP Word document in the `data/` folder:
```
data/SOP_Bank_Rate_Change_Process.docx
```

### 4. Extract SOP text

```bash
python scripts/read_sop.py
```

### 5. Set your Groq API key

Get a free key at https://console.groq.com

```bash
# Windows PowerShell
$env:GROQ_API_KEY = "gsk_your-key-here"

# Mac / Linux
export GROQ_API_KEY="gsk_your-key-here"
```

### 6. Run the web app

```bash
streamlit run chatbot/app.py
```

Open http://localhost:8501 in your browser.
